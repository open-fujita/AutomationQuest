# requirements.md

> 親 INDEX: [[INDEX]]

## 概要

1部署1クエスト化で部署が12個になった結果、ホームMAP（OfficeMapHome すごろくMAP）が縦に伸び、上（購買管理課）と下（カスタマーサポート部・マスコット）がフレームで見切れている。傾きやサイズを調整してフレーム内に収める。

## 根本原因

- 描画は固定サイズキャンバス（CANVAS_W=1300, CANVAS_H=940）に `transform: scale(SCALE)` で表示する構造
- `buildDepts` の階段配置で Z_STEP=22（高さ増分）と ROW_GAP=210（行間）が12部署では大きすぎ、内容がキャンバスの上下にはみ出す
- 外側カード（line 610）が `overflow: hidden` で、はみ出した部分がクリップされる
- キャンバスサイズが内容量に追従しない（固定値）

## 要件

- (A) 階段の傾きを緩める（Z_STEP と ROW_GAP を縮小）
- (B) 全描画要素のバウンディングボックスにキャンバスをフィットさせる（部署数非依存）
- (C) SCALE を調整してフレーム幅に収める
- 部署数が変わっても破綻しない実装にすること

## 受け入れ条件

- [ ] AC1: 12部署全てのデスク・カード・ゴール・マスコットがフレーム内に収まり見切れない
- [ ] AC2: 部署数にハードコードした値がない（将来の増減に対応）
- [ ] AC3: `npm run typecheck` exit 0
- [ ] AC4: `npm test` 253 passed 維持

- 対象外: ミッションデータ・部署構成の変更、他コンポーネント、glossary.ts
