# requirements.md

> 親 INDEX: [[INDEX]]

## 概要

相談票モーダル（`MissionBriefing`）の「相談を受ける →」ボタンの左側に「休憩する」ボタンを追加し、押すとホーム画面に戻る。

## 背景

現在の MissionBriefing モーダルには「相談を受ける →」ボタンのみで、ユーザーがホームに戻る手段がモーダル上に存在しない。「休憩する」ボタンを追加することで、ミッション開始前にホームに戻れるようにする。

## 要件

### 機能要件

- MissionBriefing モーダルのフッターに「休憩する」ボタンを追加
- ボタン配置: 左側に「休憩する」、右側に既存の「相談を受ける →」
- 「休憩する」クリックでホーム画面に戻る（既存 `goHome` を使用）
- 「休憩する」は副次的ボタンの見た目（ゴースト/アウトライン系、明テーマに合わせた配色）

### 非機能要件

- `onRest` は必須プロップ（配線漏れを型エラーで検出）
- 既存テスト 253 pass 維持
- 型チェック exit 0 維持

## 受け入れ条件

- [ ] AC1: 相談票モーダルの左に「休憩する」、右に「相談を受ける →」が表示される
- [ ] AC2: 「休憩する」クリックでホーム画面に戻る
- [ ] AC3: 「相談を受ける →」の既存動作に変更なし
- [ ] AC4: `npm run typecheck` exit 0
- [ ] AC5: `npm test` 253 passed 維持

## スコープ
